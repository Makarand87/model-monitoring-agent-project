# Previous Validation Report — Application Scorecard APP_PD_001

## Conclusion
The model was validated as fit for continued use subject to enhanced monitoring of population stability and the New-to-Credit segment.

## Key findings
Overall discriminatory performance remained acceptable at validation. Population mix had begun to shift toward New-to-Credit applicants, creating sensitivity in PSI and approval-rate measures.

## Monitoring recommendation
Monthly PSI and segment-level PSI must be reviewed. A RED PSI breach must be escalated in accordance with the Monitoring Escalation Procedure. If the New-to-Credit segment is the primary driver, management must quantify the segment contribution before concluding that the model itself has deteriorated.

## Open limitation
The model has limited historical depth for recently introduced acquisition channels. Monitoring commentary should distinguish channel-mix change from model-performance change.

## Follow-up
Targeted revalidation should be considered if RED AUC deterioration persists for two consecutive monitoring periods or if a material data/implementation issue is identified.
